# Simple Interest Calculator

A simple Bash script-based calculator that computes simple interest given the principal amount, annual rate of interest, and time period in years.

## Project Description
This project is part of the Git and GitHub final assignment. It demonstrates core version control concepts, including branching, merging, and collaborating via GitHub. It also includes a functional shell script (`simple-interest.sh`) to perform basic financial calculations.
